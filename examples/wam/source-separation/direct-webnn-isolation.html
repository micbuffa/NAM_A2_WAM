Compilation only — no audio processing

Loads the same verified Demucs graph and weights. Tests a small add baseline, the original outputs, then the ancestors of selected intermediate operations. Each probe uses a fresh WebNN context. Failed endpoints are also tested as isolated operators with cut edges replaced by inputs.

This is a compiler diagnostic, not a performance or audio quality benchmark. Changing graph outputs can change compiler behavior. A failing endpoint does not prove that its last operator is defective; successful probes do not imply successful inference. Requested CPU/GPU/NPU is not proof of physical placement.

Default: a sparse scan. To refine an interesting interval, narrow first/last and set step to 1 (maximum 64 endpoints). No assumption that failures are monotonic.

Ready. Requires native WebNN in a Worker.
