Ouvrir l’application via le serveur local

Cette page est ouverte depuis le disque (file://). Le navigateur bloque le chargement des modules et du catalogue de modèles dans ce mode.

Lancez npm start à la racine du projet, puis ouvrez le prototype à cette adresse HTTP.

Si votre serveur utilise un autre port, ouvrez la même page depuis son adresse HTTP. Le cache des modèles est propre à chaque origine (adresse et port).

    Quel modèle choisir ?
    htdemucs_ft : voix, batterie, basse et « autre » (souvent la guitare dans le rock). htdemucs_6s ajoute guitare et piano dédiés. Le modèle FT exécute quatre spécialistes successifs ; il est plus lent. Ces conversions expérimentales doivent encore être comparées à UVR sur de vrais morceaux.
