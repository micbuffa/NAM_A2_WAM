Measured backend recommendations
These are measured speed recommendations for each model, not sound quality rankings. “WebNN available” also considers WebGPU/WASM: WebNN need not win. Projections include graph setup + first processing + linear extrapolation of retained processing; downloads, runtime loading, playback and memory limits are excluded. They are estimates, not whole-song measurements. Devices must actually pass a capability test in the final app; a requested NPU is not verified physical placement. Four stems group guitar with “other”; use six stems when a dedicated guitar stem is needed. One session is provisional evidence.
