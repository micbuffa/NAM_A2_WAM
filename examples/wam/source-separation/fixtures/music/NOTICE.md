# Real music test excerpt

`slow-motion-dream.mp3` is an unmodified copy of `audio_example.mp3` from
[Deezer Spleeter](https://github.com/deezer/spleeter/tree/c8854001ac8acad34a9bc2bd15f28475541828b1), revision `c8854001ac8acad34a9bc2bd15f28475541828b1`.

Excerpt from **Slow Motion Dream**, Steven M Bryant, copyright 2011,
featuring **CSoul, Alex Beroza & Robert Siekawitch**.
Original attribution: <http://dig.ccmixter.org/files/stevieb357/34740>.
License: [Creative Commons Attribution 3.0](https://creativecommons.org/licenses/by/3.0/).
The Spleeter README provides these credits for its demo audio.

The MP3 itself has not been modified. Decoding/resampling and selecting an
excerpt happen locally during the test. This is a stereo musical mixture,
not a set of reference stems: GPU/CPU numerical agreement and remix residuals
are integration measurements, **not** SDR/SI-SDR or a quality comparison with UVR.
