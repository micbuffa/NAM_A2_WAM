# Pedal title fonts

Title fonts of the original bundled pedal GUIs, served locally (no call to Google Fonts at runtime) and loaded on
demand by `../tonelab-pedal.js` (`FONT_FILES`, `skin.font`). Latin subset, woff2, downloaded from Google Fonts on
2026-10-21.
