This is a WAM plugin built from the DSP code from the ../dsp folder, using the IFCPreampGuitarix.dsp preamp. Original code has been generated using the faust2wam script.

After the original WAM has been generated, the GUI has been modified to suit the end user better, targeting a guitar player.

In order to try out this WAM : 1) you can open the host/index.html file using an http server. 2) you can copy this entire folder somewhere and use the WAM URI like:
http://myserver.com/path/to/EndUserAmp1/index.js
